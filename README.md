# 教学系统设计复习手册

依据中国大学MOOC《教学系统设计》（闽南师范大学）公开课程介绍与八章大纲整理的离线复习站点。

## 内容

- 8 章知识清单
- 24 个知识组件
- 64 道交互练习
- 每章 MOOC 章节对照

## 离线使用

首次联网打开后，Service Worker 会缓存全部章节。之后即使断网，也可以从浏览器历史或已安装的 PWA 打开。
